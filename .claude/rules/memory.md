# Memory and Knowledge Rules

`docs/` holds in-repo technical documentation, which is the authority on how this project works. Anything a future contributor needs in order to work on this repository belongs in `docs/` or `.claude/`, never only in a personal memory or knowledge store.

Which personal stores a contributor uses, and what goes in each, is their own setup. Record it in `memory.local.md` beside this file, and read that file when it exists. Every `*.local.*` file is ignored by Git, so it is never published.
